# CopyLasso 0.2.2

CopyLasso 0.2.2 is a security-only maintenance release for the private, offline screen-text and code capture workflow shipped in 0.2.1.

## Security Update

- The shipping Sparkle updater framework is updated from 2.9.4 to 2.9.5 for
  the upstream fix documented as
  [`GHSA-gmj2-gq3j-vqmj`](https://github.com/sparkle-project/Sparkle/security/advisories/GHSA-gmj2-gq3j-vqmj).
- CopyLasso continues to publish authenticated full-package updates only.
  Delta-update generation remains disabled, and no new network destination,
  entitlement, permission, or automatic installation behavior is added.

## Privacy and Scope

Capture, OCR, supported QR/barcode recognition, clipboard output, Settings,
sound, onboarding, and Launch at Login remain unchanged. Screen pixels and
recognized content stay on this Mac, are not retained after the operation, and
are never sent through the updater. Code payloads remain inert plain text.

## Requirements and Upgrade

- macOS 14 or newer
- Apple silicon or Intel Mac
- Screen Recording permission for region capture

CopyLasso 0.1.x users must install CopyLasso 0.2.2 manually once because those
versions contain no updater. Users of updater-enabled 0.2.x keep separate
Download and Install and Relaunch decisions; updates never download or install
automatically.

## Retained Limitations

- OCR targets ordinary horizontal, single-column U.S. English text.
- Selection remains confined to one display, and protected content can be
  unavailable under macOS capture restrictions.
- Modifier-adjusted native selection geometry is unsupported; cross-display
  release cancels.
- The documented Control-at-mouse-up, dragged first-use confirmation followed
  by Escape, exceptionally fast drag, lock-during-selection, and privacy-first
  clipboard clear-then-write edge cases remain unchanged.
- LaTeX recognition, content history, file or camera input, and automatic
  updates are not included.
