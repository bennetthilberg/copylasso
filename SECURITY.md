# Security

## Supported versions

| Version | Supported |
| --- | --- |
| 0.3.x | Yes |
| 0.2.x and earlier | No |

Install the latest [CopyLasso release](https://github.com/bennetthilberg/copylasso/releases/latest)
before reporting a problem that might already be fixed.

## Report a vulnerability

Use [GitHub Private Vulnerability Reporting](https://github.com/bennetthilberg/copylasso/security/advisories/new)
to report a suspected vulnerability. Do not post security reports in a public
issue, pull request, discussion, or social post before coordinated disclosure.

Include the following information when possible:

- The affected version or component.
- Steps to reproduce the problem or a minimal proof of concept.
- The security impact and conditions required to trigger it.
- A suggested mitigation, if you have one.

Remove passwords, tokens, signing credentials, private keys, personal captures,
recognized private text, and unrelated personal data from the report.

Use the public issue tracker for bugs that have no security impact.
