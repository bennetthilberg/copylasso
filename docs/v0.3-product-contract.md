# CopyLasso v0.3 Product Contract

**Status:** Approved source contract for the unreleased v0.3 line. CopyLasso
0.2.2 remains the latest public release.

This contract amends the retained v0.2 behavior only where it explicitly says
so. The privacy, capture, code-precedence, clipboard, updater, accessibility,
and lifecycle guarantees in the [v0.2 contract](v0.2-product-contract.md)
remain in force.

## Multilingual text recognition

- U.S. English remains the only default OCR language for existing and new
  users.
- Settings contains one **Text Languages** editor populated from the languages
  supported by Apple Vision revision 3 in accurate mode on the running Mac.
- A user may search, add, remove, and order supported languages. At least one
  language is always selected, and **Reset to English** restores the default.
- The saved order is passed to Vision as recognition priority. Automatic
  language detection is enabled only when more than one language is selected.
- Each accepted Capture request snapshots the saved language selection. A
  Settings change affects the next capture, never an operation already in
  progress.
- Supported codes still take precedence over OCR. Language selection changes
  only the text fallback after a code-free selection.
- If the runtime language catalog is unavailable, CopyLasso fails closed to
  U.S. English and leaves the editor unavailable rather than inventing support.
  This temporary runtime fallback does not replace the user's saved language
  selection.

## Privacy and storage

The selected language identifiers and their priority are ordinary local
preferences. CopyLasso does not download language packs, models, or recognition
data; add a dependency or entitlement; or send language choices, screen pixels,
recognized text, or clipboard content over the network. Recognition continues
to use Apple's on-device Vision framework and the existing transient image and
text lifetimes.

## Optional capture history

- **Save Capture History** is off by default. Enabling it is one explicit
  action in Settings > Privacy and takes effect immediately.
- While enabled, only exact output from successful text and inert code captures
  is stored. Screenshots, recognition observations, source applications,
  selection geometry, prior clipboard contents, and HUD data are never stored.
- CopyLasso retains at most 100 entries for seven days. An individual entry
  larger than 256 KiB in UTF-8 is copied normally but is not saved.
- Entries are encrypted in one versioned AES-256-GCM authenticated archive in
  the sandboxed Application Support directory. Its random key is a separate,
  nonsynchronizing, this-device-only Keychain item scoped to the running
  production or Debug bundle identifier.
- Missing keys, authentication failure, truncation, unknown archive versions,
  and write errors fail closed: no stored content is exposed or silently
  overwritten, while the already completed clipboard write and sound remain
  successful.
- History offers exact Copy, immediate individual Delete, and confirmed Clear
  All. Copying an entry does not create another history event. Clear All leaves
  history enabled with a new key.
- Turning history off deletes the active archive and app-owned key. Existing or
  unreadable data requires confirmation; an empty history turns off directly.
  App-driven deletion cannot promise forensic erasure from APFS snapshots or
  external system backups.
- Decrypted window state is cleared when History closes or the session locks.
  Expiry pruning runs on launch, read, write, and an in-process timer.

## Scope

This contract adds language choice and the narrowly bounded optional capture
history above. It does not add translation, text-to-speech, handwriting
specialization, file import, layout reconstruction, a new capture command, or
a public release. Those require separate roadmap and contract approval.
