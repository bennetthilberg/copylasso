# CopyLasso v0.3 Source Qualification

G54 freezes merged source as `0.3.0 (6)` for private qualification. CopyLasso
0.2.2 remains the latest public release until the separate G56 publication
transaction completes.

## Qualified Feature Boundary

The v0.3 source delta contains only:

- the opt-in Text Languages editor and per-capture Vision-language snapshot;
- off-by-default, AES-256-GCM encrypted capture history with the approved
  retention, Keychain, failure, deletion, and lifecycle boundaries; and
- the G53 interface-copy cleanup.

The updater, success sound, unified OCR/code command, code precedence,
selection, clipboard, accessibility, and lifecycle contracts remain those
already released in v0.2.2. G39's LaTeX no-go remains in force.

## Automated Qualification

The exact final G54 head must pass:

- focused preference-migration and feature-integration tests;
- privacy, history, multilingual OCR, release, interface, and v0.3
  qualification audits exactly once through canonical CI;
- canonical arm64 and x86_64 pipelines with networking-denied and repeatability
  passes;
- a Universal 2 Release build and the maintained hosted macOS runtime check;
  and
- exact-head diff, secret, placeholder, entitlement, dependency, and review
  readback.

Real macOS 14 remains a manual release gate. A macOS 15 hosted artifact launch
does not silently qualify Sonoma behavior.

## Signed And Packaged Qualification

After the final tracked commit, G54 creates one commit-addressed private
qualification package under `~/Library/Developer/CopyLasso/G54/<commit>/`.
The package must prove production identity, `0.3.0 (6)`, both architectures,
the reviewed entitlements, every nested signature, Developer ID secure
timestamp and Hardened Runtime, an accepted notarized and stapled app, Gatekeeper,
the DMG/checksum/dSYM/verification bundle, and authenticated update-metadata
key match and tamper rejection.

No protected release workflow was dispatched and nothing was uploaded or
published during G54.

## Signed Host Matrix

One Apple Development-signed Debug build covers Settings, About, updater and
sound state, ordinary OCR, representative runtime languages, all five code
formats and code precedence, no-result and Escape, rapid reuse, permission
denial/recovery, Launch at Login reconciliation, encrypted history opt-in,
relaunch persistence, copy/delete/clear/disable, lock cleanup, keyboard and
VoiceOver traversal, and light/dark/accessibility appearances. Performance and
idle evidence remain bounded to the v0.3 delta rather than relabeling
historical G24 rows.

## G55 Handoff

Only after the G54 PR is separately merged to protected `main` may the
maintainer authorize one G55 protected dispatch. The workflow derives
`v0.3.0-rc.N` from canonical metadata and creates a private draft with exactly
the DMG, checksum, dSYM, and verification bundle. Candidate approval remains a
separate gate before G56 publication.
