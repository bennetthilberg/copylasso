## Installed Public Application

The installed `/Applications/CopyLasso.app` is byte-identical to the application
inside the exact public DMG. Its readback reports the production bundle
identifier, version `0.2.0`, build `3`, and both `arm64` and `x86_64` slices.
Launch Services was reduced to one production CopyLasso registration at that
installed path without deleting archived qualification evidence or resetting
unrelated application registrations. A reset scoped only to production
CopyLasso removed its stale duplicate Screen Recording record; System Settings
then showed one enabled, branded CopyLasso entry and left every unrelated
privacy row unchanged.

G43's exact package qualification passed Developer ID, Hardened Runtime,
entitlement, nested-code, notarization, stapling, Gatekeeper, Universal 2, and
two-item read-only DMG checks before publication. During the G44 readback on the
same host, the exact digest-matching bytes reproduced the previously documented
macOS 26 command-line provenance anomaly: one Gatekeeper assessment recognized
the notarized Developer ID application, while later `codesign` and `stapler`
invocations returned local subsystem errors. The immutable bytes, GitHub
digests, mounted/installed byte comparison, authenticated appcast, and prior
strict qualification all remained unchanged; this record does not relabel the
host anomaly as a fresh strict pass.

## Shipped Scope And Issues

Public 0.2.0 ships the user-controlled authenticated updater, the configurable
candidate-17 success sound, and unified local OCR plus QR, Code 128, Data Matrix,
PDF417, and Aztec recognition. Code payloads remain inert plain text and an
eligible code takes precedence over OCR in the same selection.

Issue [#36](https://github.com/bennetthilberg/copylasso/issues/36) closed after public updater verification.

Issue [#38](https://github.com/bennetthilberg/copylasso/issues/38) closed after public code-recognition verification.

Issue [#49](https://github.com/bennetthilberg/copylasso/issues/49) remains open because v0.2.0 contains no LaTeX recognizer.

The v0.2 product contract, privacy and security documentation, changelog, and
download instructions now describe the public release. The later G43A
release-note presentation fix remains under `Unreleased`: it was merged after
publication and is not present in immutable public 0.2.0 bytes.
