# CopyLasso v0.2 Source Qualification

**Version/build:** `0.2.0 (3)`
**Execution status:** In progress during G41
**Public status:** Public release remains `0.1.1`.

This record freezes and qualifies the source intended for CopyLasso v0.2
without creating a release candidate or publishing an updater feed. G42 is a later release gate that may create one immutable private candidate only after
G41 merges to protected `main`.

## Frozen Feature Set

- One Capture command and configurable shortcut recognize ordinary horizontal
  U.S. English text plus QR, Code 128, Data Matrix, PDF417, and Aztec codes.
  An eligible code result wins over OCR text; otherwise Capture falls back to
  text.
- The user-controlled Sparkle updater checks one fixed authenticated feed.
  Automatic checks default on and can be disabled. Download and installation
  each require separate user consent.
- One original success sound defaults on, can be disabled independently, and
  plays only after a successful clipboard write.
- G39 concluded no-go. Version 0.2 contains no LaTeX recognizer, model, runtime,
  command, dependency, or precedence branch.

## Performance Protocol

- Record 30 ordinary OCR and 30 code capture-to-clipboard samples. Each series
  must have median at most one second and nearest-rank p95 at most two seconds.
- After a 30-second settle, sample CPU, private memory, and RSS once per second
  for 60 seconds. Settled CPU must remain below 1% on the maintainer host.
- Run 100 mixed text/code/success/cancellation cycles, recording private memory
  and RSS every ten cycles. Require bounded plateau behavior, zero reported
  leaks, complete cleanup, and no retained private content.

### Current Result

After a 30-second settle, 60 one-second samples of the clean signed app
reported 0.0% CPU throughout and a constant 16 MiB resident-memory display.
The detailed physical-footprint sampler recorded 61 observations from
16,417,584 to 16,433,968 bytes, a one-page 16,384-byte difference, with a
16,663,320-byte peak. This **passes** the idle CPU requirement and shows no
unbounded idle growth.

The production integration suite passed 100 alternating text/code results in
one reusable coordinator, plus separate alternating success/cancellation and
image/string-release coverage. Attempts to automate real signed selection
timing through the current UI harness could not reliably deliver the status
item or live selection events. Consequently the physical 30-text and 30-code
latency series, signed-process ten-cycle memory checkpoints, and Instruments
leak result remain **Blocked**, rather than borrowing historical G24 timing or
promoting service-boundary tests into physical measurements.

## Retained Limitations

The release continues to document ordinary horizontal single-column U.S.
English OCR, single-display selection clamping, protected-content restrictions,
stationary immediate-reuse crosshair delay, lock-during-active-drag recovery,
and the rare privacy-first clipboard clear-then-write failure. Code recognition
is limited to the five listed formats and deliberately refuses to merge
multiple unique multiline payloads. Existing 0.1.x users must manually install
the first updater-enabled release.

No G41 result publishes a feed, tag, release, website, Mac App Store build, or
Homebrew package.
