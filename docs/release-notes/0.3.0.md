# CopyLasso 0.3.0

CopyLasso 0.3.0 adds user-selected on-device OCR languages and optional,
encrypted capture history while retaining the private, local screen-text and
code workflow from 0.2.2.

## What Is New

- **Choose Text Languages.** Settings now includes a Text Languages editor
  backed by the languages available to Apple Vision on the running Mac.
  U.S. English remains the default. Users can search, add, remove, and prioritize
  languages; automatic language detection runs only when more than one is
  selected.
- **Optional private capture history.** Save Capture History is off by default.
  When explicitly enabled, CopyLasso encrypts the exact successful text or
  inert code payload locally with AES-256-GCM. It keeps at most 100 entries for
  seven days, rejects entries larger than 256 KiB, and never stores screenshots.
  Copy, Delete, confirmed Clear All, and confirmed disable
  controls remain local to the Mac.
- **Cleaner interface copy.** CopyLasso-authored menu labels, buttons,
  progress messages, and bounded HUD previews no longer add ellipses. Captured
  text, code payloads, and authenticated update notes are never rewritten.

## Privacy And Security

Recognition remains local and offline. Selected screen pixels, recognized
content, clipboard contents, and language choices are never sent through the
updater. History creates no key or archive until opt-in. Its random key is a
device-only, nonsynchronizing Keychain item scoped to CopyLasso, and unreadable
or tampered archives fail closed without affecting an already successful copy.

CopyLasso still checks only its authenticated GitHub-hosted update feed. It
does not automatically download or install updates, and it requires separate
Download and Install and Relaunch decisions.

## Requirements And Upgrade

- macOS 14 or newer
- Apple silicon or Intel Mac
- Screen Recording permission for region capture

CopyLasso 0.2.2 users can install 0.3.0 through Check for Updates after the
release is published. Existing shortcut, Launch at Login, updater, sound, and
permission-history preferences are retained. Existing and new users begin
with U.S. English selected and Save Capture History off unless they explicitly
changed those new settings in a prerelease build.

CopyLasso 0.1.x users must install the current public DMG manually once because
those versions contain no updater.

## Uninstall

For an ordinary uninstall, turn off Launch at Login, quit CopyLasso, and move
the app to the Trash. A complete uninstall additionally removes only
CopyLasso's production preferences and sandbox container, deletes its scoped
history Keychain item, and resets Screen Recording only for
`io.github.bennetthilberg.copylasso`. Do not reset unrelated login items,
Keychain entries, or privacy services.

## Retained Limitations

- OCR targets ordinary horizontal, single-column text. Complex layouts,
  handwriting, and strongly rotated text can be inaccurate.
- Selection remains confined to a single display, and protected content can be blank or
  unavailable under macOS capture restrictions.
- Supported QR, Code 128, Data Matrix, PDF417, and Aztec payloads remain inert
  plain text and take precedence over OCR when both appear in one selection.
- The documented Control-at-mouse-up, exceptionally fast drag, cross-display
  release, lock-during-selection, and privacy-first clipboard clear-then-write
  edge cases remain.
- History deletion cannot promise forensic erasure from APFS snapshots or
  external system backups.
- LaTeX recognition is not included. Translation, text-to-speech, file import,
  cross-display selection, and layout reconstruction remain outside v0.3.
