# CopyLasso 0.2.1

CopyLasso 0.2.1 is a maintenance release for the private, offline screen-text
and code capture workflow introduced in 0.2.0.

## What Is Fixed

- Update offers render authenticated Markdown as native headings, emphasis,
  paragraphs, and lists inside a bounded, scrollable panel instead of showing
  raw syntax or expanding beyond the display.
- Capture starts macOS's native crosshair without activating CopyLasso or
  changing the frontmost application, then sends only the selected rectangle
  through the existing in-memory ScreenCaptureKit and Vision pipeline.
- Permission denial, unavailable capture, lifecycle cancellation, stale
  completion, cross-display release, and modifier-sensitive selection paths
  fail closed and remain immediately reusable.
- Update labels and privacy copy are shorter, and About has clearer spacing.
- Protected release automation has tighter source, credential, candidate-tag,
  archive-path, nested-code, and authenticated-update verification boundaries.

## Privacy And Scope

No recognition mode, permission, entitlement, dependency, or network path is added.
OCR and supported QR/barcode recognition remain local; recognized content,
screen pixels, and clipboard text are not transmitted or retained. No processing indicator is included.

## Native Selector Notes

macOS may show a one-time direct screen-access confirmation for the system
selector. This is part of Screen Recording access, not a new CopyLasso
permission or entitlement.

The passive selection tracker uses one-millisecond pointer samples and does not
intercept or synthesize input. An entire exceptionally fast drag can therefore
be missed or begin at the first observed point. Control at mouse-up can race
with macOS's screenshot-to-clipboard behavior before CopyLasso cancels, and a
dragged first-use confirmation followed immediately by Escape can rarely leave
candidate geometry. A cross-display release cancels instead of cropping or
combining displays. Retry with an ordinary direct drag when one of these narrow
cases occurs.

## Requirements

- macOS 14 or newer
- Apple silicon or Intel Mac
- Screen Recording permission for region capture

CopyLasso 0.1.x users must still install public 0.2.0 manually once before
authenticated in-app updates are available. CopyLasso remains free and open
source under the MIT License.
