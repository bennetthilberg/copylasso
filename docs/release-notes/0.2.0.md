# CopyLasso 0.2.0

CopyLasso is free and open-source screen recognition for macOS. Capture remains
private, offline, and local: selected pixels and recognized content stay on
this Mac and are not retained after the operation.

## What Is New

- **User-controlled secure updates.** Automatic checks are enabled by default
  and can be disabled in Settings. Manual checks remain available. CopyLasso
  authenticates signed metadata and packages, shows the version, notes, and
  size before download, and requires a second confirmation before installation
  and relaunch. Downloads and installations never begin automatically.
- **Friendly copy feedback.** A brief project-authored success sound plays only
  after recognized content reaches the clipboard. It can be disabled
  independently in Settings; visual and accessible feedback remains available.
- **Codes through the existing Capture command.** CopyLasso recognizes QR,
  Code 128, Data Matrix, PDF417, and Aztec codes from the selected screen
  region. An eligible code wins over OCR text in the same selection. If no
  supported code is present, ordinary English OCR runs as before. Payloads are
  copied as inert plain text and are never opened or executed.

Supported formats are QR, Code 128, Data Matrix, PDF417, and Aztec.

CopyLasso 0.1.x does not contain an updater. Existing users must manually
download and install CopyLasso 0.2.0 once before later authenticated in-app
updates can become available.

## Requirements

- macOS 14 or newer
- Apple silicon or Intel Mac
- Screen Recording permission for region capture

## Known Limitations

- OCR targets ordinary, approximately horizontal, single-column U.S. English
  text. Handwriting, dense tables, strongly rotated text, and complex
  multi-column layouts can be incomplete or reordered.
- Selection remains confined to the display where the drag begins.
- Protected content can appear blank or unavailable under macOS capture
  restrictions.
- Supported code recognition is limited to the five formats listed above.
  Multiple unique payloads containing line breaks are intentionally not merged;
  capture those codes separately.
- Immediate stationary-pointer reuse can briefly delay the visible crosshair
  until pointer movement or mouse-down.
- Locking during an active drag can leave selection pending after unlock. Quit
  and reopen CopyLasso before another pointer action; completing that retained
  selection can change the clipboard.
- A rare macOS pasteboard clear-success followed by text-write rejection can
  leave the clipboard empty. CopyLasso does not read or retain prior clipboard
  contents in order to restore them.
- LaTeX recognition is not included. G39 found no candidate that satisfied the
  approved licensing, platform, size, hardware, and quality preconditions.

## Complete Uninstall

Disable **Launch CopyLasso at Login** in Settings, quit CopyLasso, and move the
application to the Trash. To remove only CopyLasso's production state, delete
the `io.github.bennetthilberg.copylasso` preferences and sandbox container, then
reset only `ScreenCapture` for that exact bundle identifier. Do not reset every
login item or every application's Screen Recording permission.
